# 随行 APK 下载服务 — Ubuntu 部署指南

## 一、服务器环境

```bash
# 安装 Python 3.12+ venv 和依赖
sudo apt update
sudo apt install -y python3.12 python3.12-venv
```

---

## 二、上传项目到服务器

将 `Z:\SoftwareCupAI_Download` 整个项目上传到服务器，假设放在 `/home/download/`：

```
/home/download/
├── main.py
├── requirements.txt
├── static/
│   └── index.html
└── uploads/
    └── apk/
        └── SoftwareCup-v1.0.0.apk
```

---

## 三、创建虚拟环境并安装依赖

```bash
cd /home/download
python3.12 -m venv venv
./venv/bin/pip install -r requirements.txt
```

---

## 四、创建 systemd 服务

```bash
sudo nano /etc/systemd/system/suixing-download.service
```

写入：

```ini
[Unit]
Description=随行 APK 下载服务
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/home/download
Environment=PATH=/home/download/venv/bin:/usr/local/bin:/usr/bin:/bin
ExecStart=/home/download/venv/bin/python main.py
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

---

## 五、启动并设为开机自启

```bash
sudo systemctl daemon-reload
sudo systemctl start suixing-download
sudo systemctl enable suixing-download
```

---

## 六、验证

```bash
# 查看状态
sudo systemctl status suixing-download

# 测试接口
curl http://localhost/api/apk/info

# 浏览器访问
# http://服务器IP
```

---

## 七、日常管理

| 操作 | 命令 |
|------|------|
| 查看状态 | `sudo systemctl status suixing-download` |
| 查看日志 | `sudo journalctl -u suixing-download -f` |
| 停止服务 | `sudo systemctl stop suixing-download` |
| 重启服务 | `sudo systemctl restart suixing-download` |
| 更新代码后重启 | `sudo systemctl restart suixing-download` |
| 禁止开机自启 | `sudo systemctl disable suixing-download` |

---

## 八、更新 APK 版本文件

1. 把新 APK 上传到 `/home/download/uploads/apk/`
2. 编辑 `main.py` 修改 `APK_META` 中的 `version` / `version_code` / `filename` / `changelog`
3. 重启服务：`sudo systemctl restart suixing-download`
