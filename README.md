# 随行 · 文旅数字人

面向景区游客和管理人员的多端应用。游客端、管理端和下载服务按各自入口构建。

- 服务端可读 [游客 API](visitor-api/README.md)、[管理 API](admin-api/README.md) 和 [下载服务](download-service/README.md)。
- 客户端可读 [Vue 管理 Web](admin-web/README.md)、[原生 Android](android/README.md)、[UniApp](uniapp/README.md) 和 [Android H5 外壳](android-shell/README.md)。
- 历史快照包括 [UniApp 副本](legacy/uniapp-variant/README.md)、[游客 API](legacy/test-visitor-api/README.md)、[管理 API](legacy/test-admin-api/README.md) 和 [管理 Web](legacy/test-admin-web/README.md)。

面试可用一个配置或对话请求串联前端页面、API 和数据模型，再说明客户端与后台的职责边界。
