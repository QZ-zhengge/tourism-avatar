## 一、项目概览

| 项目 | 说明 |

| 项目名称 | HBuilderX APP 后端服务 |

## 四、数据库设计

### 4.1 数据库配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 数据库类型 | MySQL 8.0 | — |
| 字符集 | utf8mb4_unicode_ci | 支持 emoji 和中文 |
| 连接池 | QueuePool (pool_size=5) | SQLAlchemy 管理 |
| 连接检测 | pool_pre_ping=True | 自动重连 |
| 建表策略 | auto check-first | 启动时自动创建缺失表 |

### 4.2 数据表（6 张）

| 表名 | 记录数 | 说明 |
|------|--------|------|
| `users` | 1 | 用户表（username/email/phone_number 唯一索引） |
| `posts` | N | 帖子表（软删除，status 字段） |
| `post_images` | N | 帖子图片表（CASCADE 级联） |
| `post_videos` | N | 帖子视频表（CASCADE 级联） |
| `post_likes` | N | 点赞记录表（联合唯一索引防重复） |
| `post_comments` | N | 评论表（自关联 parent_id 支持树形回复） |

### 4.3 表关系

```
users (1) ──< posts (N)
                │
                ├──< post_images (N, CASCADE)
                ├──< post_videos (N, CASCADE)
                ├──< post_likes (N, CASCADE)
                └──< post_comments (N, CASCADE)
                         │
                    self-ref: parent_id → id
```

## 五、模块详解

### 5.1 用户模块

| 端点 | 说明 |
|------|------|
| `POST /user/register/` | 注册（校验用户名/邮箱/手机号唯一性，SHA256 密码哈希） |
| `POST /user/login/` | 登录（明文密码验证，返回用户信息） |

### 5.2 驴友圈社交模块

| 子模块 | 端点 | 核心特性 |
|--------|------|----------|
| 帖子 | 7 个端点 | CRUD + 多媒体绑定 + 分页 + 可见性控制 |
| 点赞 | 4 个端点 | Toggle 机制（复用点赞/取消）、原子计数更新 |
| 评论 | 3 个端点 | 树形结构（一级评论 + nested replies）、软删除 |

### 5.3 文件上传模块

| 端点 | 限制 |
|------|------|
| `POST /upload/image` | 单张 JPG/PNG/GIF/WEBP，≤ 10MB |
| `POST /upload/images` | 批量最多 9 张 |
| `POST /upload/video` | 单个 MP4/MOV/AVI/WEBM，≤ 100MB |

文件命名规则：`时间戳_UUID.扩展名`

### 5.4 讯飞虚拟人模块

| 端点 | 功能 | 协议 |
|------|------|------|
| `POST /avatar/start` | 启动会话（avatar_id / width / height / protocol / bg_transparent）| HTTPS |
| `POST /avatar/drive/text` | 文本驱动 TTS（vcn / speed / pitch / actions）| HTTPS |
| `POST /avatar/drive/audio/url` | 获取 WSS 鉴权 URL（uniapp 直连模式）| HTTPS |
| `POST /avatar/drive/audio/proxy` | 音频帧代理转发（服务端中转模式）| HTTPS + WSS |
| `POST /avatar/stop` | 停止会话 | HTTPS |
| `POST /avatar/ping` | 心跳保活（建议每 30s）| HTTPS |
| `GET /avatar/session/{id}` | 查询本地会话缓存 | HTTPS |
| `GET /avatar/actions/{id}` | 形象动作列表 | HTTPS |
| `GET /avatar/vcn/list` | 发音人列表（12 人）| HTTPS |

**架构角色**：安全代理层，APIKey/Secret 不暴露给客户端，后端完成 HMAC-SHA256 鉴权。

### 5.5 Vosk 流式语音识别模块

| 端点 | 功能 | 协议 |
|------|------|------|
| `WS /asr/stream` | 真正流式 ASR（逐帧解码，< 500ms 延迟）| WebSocket |
| `GET /asr/status` | 模型加载状态查询 | HTTP |
| `POST /asr/preload` | 预热加载模型 | HTTP |
| `GET /asr/models` | 本地已下载模型列表 | HTTP |

**技术特点**：
- 基于 Kaldi 混合系统的逐帧解码
- 支持 WAV/MP3/M4A/OGG/FLAC/AMR/PCM 等格式
- 推荐模型：`vosk-model-small-cn-0.22`（42MB）
- 无需 GPU，纯 CPU 推理

### 5.6 高德天气模块

| 端点 | 功能 | 说明 |
|------|------|------|
| `GET /weather/current` | 实况天气 | 实时温湿度/风向/天气现象 |
| `GET /weather/forecast` | 预报天气 | 未来 3~4 天白天/夜间预报 |
| `GET /weather/query` | 通用查询 | 可指定 base（实况）或 all（预报）|

**架构角色**：代理层，AMAP_API_KEY 保护在 .env 中。

## 七、部署要点

| 项目 | 说明 |
|------|------|
| Python 版本 | 3.12（使用项目 .venv 虚拟环境） |

## 八、安全策略

| 策略 | 说明 |
|------|------|
| 密码加密 | SHA256 双重哈希 |
| API 密钥保护 | 讯飞/高德密钥存 .env，不暴露给客户端 |
